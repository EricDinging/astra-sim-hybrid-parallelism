1 · The real machine in one picture

Cubes are interchangeable atoms. Fixed electrical wiring inside each N×N×N cube; every link between cubes is an optical circuit. Distance does not exist (R4) — the only scarce thing is that each surface port holds one circuit at a time (R5). The "big torus" is just one switch configuration.

2 · The rules (R1–R7)

rulestatement
R1 cubes are atomsN×N×N chips, static electrical mesh inside; never rewired.
R2 optical seams onlyOnly surface chips have an outward port, and every such port goes to an OCS. Interior chips can never leave the cube.
R3 legality (corrected)Same axis + same within-face position (i,j). Cross-cube: any polarity (+x↔−x and +x↔+x). Same cube: only +x(i,j)↔−x(i,j) — the one-cube-wide ring wrap.
R4 no proximityAny two distinct cubes are potentially one OCS hop apart; floor position is meaningless. Potential, not standing, connectivity.
R5 port exclusivityOne circuit per port at a time — the entire resource problem.
R6 free ring closureThe wrap link of a chain is an ordinary circuit.
R7 cube-granular, isolated slicesReal jobs get whole-cube private tori; no shared fabric between slices.

3 · Simulator dispositions (S1–S3)

assumptiondispositionmeaning
S1 static base torus with free adjacent seams REVISED Default torus = initial OCS configuration, not hardware. No behavior change (S3 keeps the shared fabric); finish by dropping the ocs_links tiebreak from the default rank key and relaxing the realizability predicate to corrected R3.
S2 sub-cube placements, arbitrary even shapes KEPT (extension) Research question: what would a TPU-style cluster gain from sub-cube slices, and what does support cost?
S3 shared fabric (multi-hop default routing) KEPT (extension) Same framing: deliberately beyond R7 isolation to study what shared-fabric support takes.

4 · What stays true regardless (evidence)

The class gate survives S1's revision — it was never about adjacency. Removing it (uniform-seams experiment, 8×20k-job runs): mean JCT 7.2 s → 43–65 s at fifo/0.60, with eager gluing rising only 0.8% → 3%. The gate protects clean cubes: awkward shapes must dirty some cube, and eager scattering dirties several per job, starving future jobs. Whole-cube placements dirty nothing and are unconditionally fine.

Current model is conservative: the opposite-face-only predicate rejects wirings the real machine allows (corrected R3), so every simulated placement is realizable, but the machine's full flexibility is understated until the predicate is relaxed.
